# F4 — 资产面板 (`asset_ui`)

> 模块职责：文件浏览/搜索/预览。

---

## 子任务

### 1. 资产列表（左侧栏 Tab + 独立页面）

- [ ] 1.1 创建 `AssetPanel` 组件（用于左侧栏 Tab 内嵌显示）
- [ ] 1.2 搜索框：SearchInput 组件（关键词搜索文件名）
- [ ] 1.3 `FileTypeFilter`：类型筛选按钮组（全部/CSV/Excel/PDF/图片/其他）
- [ ] 1.4 文件列表：图标 + 文件名 + 文件大小 + 上传日期
- [ ] 1.5 文件类型图标：根据 file_type 显示不同图标（FileSpreadsheet/FileText/FileImage/FileArchive 等）
- [ ] 1.6 点击文件 → 触发预览
- [ ] 1.7 文件上传按钮（📎）

### 2. 独立资产页面 (`/assets`)

- [ ] 2.1 创建 `AssetPage` 组件：更宽阔布局
- [ ] 2.2 左侧目录树：按类型/标签/上传时间组织
- [ ] 2.3 右侧：文件列表 + 预览区
- [ ] 2.4 实现文件上传（拖拽上传区域 + 点击上传）

### 3. 文件预览 (`AssetPreview`)

- [ ] 3.1 图片（PNG/JPG）：缩略图网格 + 点击放大灯箱（Lightbox）
  - 灯箱：居中大图 + 左右切换 + 关闭按钮 + 半透明背景
- [ ] 3.2 PDF：内嵌 PDF.js 查看器（iframe 嵌入 `pdf.worker.js` + `pdf.js`）
  - 翻页控制
- [ ] 3.3 文本/代码/JSON：Shiki 代码高亮（复用 F6 的 CodeBlock 组件）
- [ ] 3.4 CSV/Excel：表格渲染（ag-grid 社区版或自定义 TanStack Table 组件）
  - 支持排序、筛选
- [ ] 3.5 其他文件类型：显示文件元数据（名称 + 大小 + 类型 + 上传时间）+ 下载按钮
- [ ] 3.6 预览在模态框或侧边面板中展开（不离开当前页面上下文）

### 4. 文件操作

- [ ] 4.1 下载按钮：触发文件下载
- [ ] 4.2 删除按钮：确认对话框 → API 调用
- [ ] 4.3 重新处理按钮（知识库文档）：触发 RAG 重新索引
